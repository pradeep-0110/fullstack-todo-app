# 📝 Fullstack To-Do App

A simple full-stack To-Do application built with **React (Vite)**, **Flask**, and **SQLite**.

---

## 🚀 Features

* Add tasks
* Edit tasks
* Delete tasks
* Mark tasks as completed ✅
* Filter (All / Completed / Pending)
* Press **Enter** to add tasks
* Data persists using SQLite

---

## 🛠️ Tech Stack

* Frontend: React (Vite)
* Backend: Flask
* Database: SQLite

---

## 📂 Project Structure

```
backend/   → Flask API + SQLite DB  
frontend/  → React app (Vite)  
```

---

## ▶️ Run Locally

### 1. Backend

```
cd backend
python -m venv venv
venv\Scripts\activate   # Windows
pip install -r requirements.txt
python app.py
```

---

### 2. Frontend

```
cd frontend
npm install
npm run dev
```

---

## 🌍 Deployment

* Frontend: Vercel
* Backend: Render

## 📌 Notes

* Backend runs on `http://127.0.0.1:5000`
